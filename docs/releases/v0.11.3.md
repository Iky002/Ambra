# Ambra v0.11.3 Release Notes / 版本发布说明

## 简体中文

### 安全加固与网络边界 (Security & Hardening)
- **`LoopbackStreamProxy` HLS 清单防绕过与跨跳转加固**：
  - 将上游响应首包探测升级为循环缓冲读取，彻底消除分块短包或 UTF-8 BOM 导致的 `#EXTM3U` 嗅探绕过与 FFmpeg SSRF 风险；
  - 跨 Host 重定向拨号强制切换为纯公网 `DialContext`（禁止回环与私网 IP），阻断 `AllowPrivateLAN=true` 下的跨跳转 DNS Rebinding；
  - 跨 Host 30x 跳转自动剥离 `.strm` 传入的全部自定义认证请求头（保留 `User-Agent`）。
- **备份恢复配置清洗增强**：`ambra.json` 恢复清洗在剥离 `ffmpeg_path` / `ffprobe_path` 的基础上同步剥离 `web_dir` 与 `data_dir` 并保留宿主机原值，防止恶意备份包通过 `/web/*` 暴露数据目录。
- **登录限流与初始化门禁加固**：
  - `AuthenticateByName` 与 `Users/{Id}/Authenticate` 新增纯 IP 聚合失败计数桶并将满桶策略改为确定性 fail-closed / 最旧时间戳淘汰，封堵用户名喷洒、随机桶驱逐绕过与 Argon2id 算力 DoS；
  - `POST /api/setup/admin` 初始化完成后直接快速返回 `403` 不再写入限流 Map，并增加 IPv6 `/64` 归一化与桶数量硬上限。
- **RBAC 与协议细节加固**：
  - Watch Party 列表与详情对非房间成员自动脱敏清空 `Messages` 聊天记录；
  - 受信任反向代理 TLS 终结下，`IsSameOrigin` 识别 `X-Forwarded-Proto: https` 拦截跨协议 `http://` 降级 Origin；
  - `QueryItems` 全部 17 个剩余列表筛选参数统一接入 `json_each` 分流，彻底消除 SQLite `32766` 绑定变量上限 500 报错；
  - `GroupItemsIntoCollections=true` 合集按库/父目录筛查子项时严格套用家长控制策略，`GetItemCountsForUser` 排除他人私有播放列表计数。

### 稳定性、流媒体与插件修复 (Stability & Compatibility)
- **插件配置与扫描器并发修复**：`pluginadmin` 查找插件后立即收敛为规范 `canonicalID`，避免非规范大小写请求覆盖清空插件密钥；`Scanner` 全部改为通过 `cfg.Snapshot()` 无锁安全读取配置字段，消除并发数据竞态。
- **音频与 DVR HLS 修复**：对齐音频 HLS `main.m3u8` 与分片默认 `PlaySessionId`（`"main"`），消除 `SimultaneousStreamLimit == 1` 下的 `429` 与孤儿会话；DVR 录播动态 HLS 自动透传请求头认证 Token 至 `api_key`；音频直出与 DVR 录播直出纳入并发流上限管控。
- **测试工程化整理**：全仓库测试文件按模块与功能域规范命名，清理全部历史版本号/批次命名残留。

### Web 影院、管理台、Demo 与 10 国语言 (Web UI, Admin, Demo & i18n)
- **前端核心与播放器**：修复 `AuthContext` 跨标签页同账号刷新 Token 导致 `userLoading` 永久卡死；修复 `PlayerPage` 快速切换 ASS 字幕的异步清理竞态与 `WasmRemuxer` 加载中途 `dispose()` 泄漏；修正多处 React Query 缓存失效键（`['items']` → `['libraryItems']`）及删项后的剧集/专辑联动刷新。
- **管理控制台与 Demo 同步**：修复 `SettingsTab` 无法保存无损 `H264Crf = 0` 及 `LiveTvTab` 频道映射草稿未重置问题；在线 Demo 补齐服务器重启/关机、HDHomeRun 局域网扫描、Sync 离线任务队列及多项 RBAC 策略对齐。
- **10 国语言全量收口**：补齐 `ProfilePage`、`TrendingPage`、`NotificationBell`、`SearchPage`、`HomePage`、`Layout`、`LibrariesTab` 及 Context 提示的 10 语种翻译（共 **2,040 组词条 × 10 语种**，100% 奇偶与占位符对齐）。

## English

### Security & Network Hardening
- **`LoopbackStreamProxy` HLS Sniffing & Cross-Host Redirect Hardening**:
  - Replaced single-read initial sniffing with an iterative buffer reader so short chunked packets or UTF-8 BOM prefixes can never bypass `#EXTM3U` detection and trigger FFmpeg SSRF;
  - Enforced strict public-only `DialContext` on cross-host redirects even when `AllowPrivateLAN=true` to prevent DNS rebinding, and stripped custom upstream headers (except `User-Agent`) across cross-host redirects.
- **Backup Restore Config Sanitization**: Extended `ambra.json` restore sanitization to strip `web_dir` and `data_dir` (preserving host values) alongside `ffmpeg_path` / `ffprobe_path`, preventing unauthenticated file exposure via `/web/*`.
- **Rate Limiting, CORS & Policy Hardening**:
  - Added per-IP aggregate failure buckets and deterministic fail-closed / oldest-entry eviction on login endpoints to block username spraying and Argon2id DoS; added post-setup fast-path, IPv6 `/64` normalization, and hard bucket caps on `/api/setup/admin`;
  - Redacted Watch Party `Messages` for non-members on `GET /Parties` and `GET /Parties/{Id}`; honored trusted-proxy `X-Forwarded-Proto: https` in `IsSameOrigin`;
  - Applied `json_each` safe set binding across all 17 remaining `QueryItems` list filters, enforced parental filters in `GroupItemsIntoCollections` scoped subqueries, and excluded other users' private playlists from `GetItemCountsForUser`.

### Stability, Streaming, Web UI & 10-Locale Parity
- **Backend Stability**: Canonicalized plugin IDs in `pluginadmin` to prevent secret wipes on non-canonical casing; replaced unsynchronized `Scanner` config field reads with `cfg.Snapshot()`; aligned Audio HLS default `SessionKey` (`"main"`), propagated header tokens into DVR live-recording HLS playlists, enforced `SimultaneousStreamLimit` on audio/recording direct streams, and normalized all repository test filenames by module and feature.
- **Web UI, Admin, Demo & 2,040-Key 10-Locale i18n**: Fixed `AuthContext` cross-tab token rotation deadlock, `PlayerPage` async ASS teardown race, `WasmRemuxer` mid-load `dispose()` leak, `['libraryItems']` React Query invalidation keys, `SettingsTab` lossless `H264Crf = 0`, `LiveTvTab` stale draft mappings, missing Demo admin endpoints (`Restart`/`Shutdown`/`Tuners/Discover`/`Sync/Jobs`) & RBAC parity, and completed 10-locale localization across remaining theater pages and contexts (**2,040 keys × 10 languages**).
