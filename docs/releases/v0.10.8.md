## Trakt 按用户独立绑定

- 管理员在「管理控制台 → 插件 → Trakt」控制是否向用户开放 Trakt，默认关闭。
- 每位用户在「个人中心 → Trakt 账号」填写自己的 Client ID 和 OAuth Access Token，分别设置播放进度与已看记录同步；Token 保存后不回显，过期后需自行更新。
- 播放事件使用实际用户的账号，未绑定用户不会上报；解除绑定不会影响其他用户。管理员停用插件后，所有用户停止同步，已有绑定仍可解除。
- 修复通知类插件无法被插件管理器发现、Trakt 配置接口返回 404 的问题。

### 升级注意

**v0.10.7 及更早版本的全局 Trakt 账号配置会被移除，不会自动归属任何用户。升级后请各用户在个人中心重新绑定。** 全局启用状态保留，其他插件不受影响。

### English

Trakt credentials and sync preferences are now private to each Ambra user. Administrators control global availability; users configure their own Client ID and OAuth Access Token in Profile. Legacy global credentials are removed on upgrade and each user must reconnect. Expired tokens require a manual update.
