# Ambra v0.12.2 Release Notes / 版本发布说明

## 简体中文

### 安全加固与网络边界 (Security & SSRF Hardening)
- **HLS / DASH 代理防绕过（Critical 修复）**：
  - `LoopbackStreamProxy` 与 LiveTV HLS 清单重写器统一先将 `\r\n` 及裸 `\r` 归一化为 `\n`，支持 `URI = "..."` 等号两侧空格，并对任何残留未重写 `URI=` 标签 fail-closed 丢弃；
  - `LoopbackStreamProxy` 首包嗅探（兼容 UTF-8 / UTF-16 BOM）直接拦截 `<?xml`、`<MPD`、`<SmoothStreamingMedia` 清单（返回 `502`），阻断 FFmpeg `dash` 解复用器绕过代理直连内网或云元数据；
  - `isSameOriginHost` 增加协议（`http`/`https`）比对，`/sub` 绑定重定向后 `effectiveURL` 源站，`Close()` 回收自有空闲 HTTP 连接池。
- **通知服务、远程访问与账号安全加固**：
  - 普通用户配置的通知服务强制执行公网 URL 校验（禁止内网 SSRF），修改目标源站自动清空脱敏密钥，投递切换为 4-worker 有界并发池，删除用户联动清理 `compatext:state` 通知记录；
  - 未登录公网请求严格执行全局与用户级 `EnableRemoteAccess` 策略（覆盖用户头像、`GET /Users/Public`、初始化向导 `/api/setup/admin` 与 `/Startup/*`）；运行时关闭全局远程访问或收紧内网网段后立即断开存量公网 WebSocket 连接；
  - 禁用账号登录先执行等时虚拟校验再统一返回 `ErrUserDisabled`（消除密码预言机）并记入限流桶与活动日志节流；HTTP 服务设置 `ReadTimeout: 60s`（大文件相机上传与 WebSocket 自动豁免/延长），头像上传与显示偏好超限返回 `413` 并原子落盘。
- **权限隔离与文件系统防越界**：
  - 封堵 `GET /Items/Latest` 与 `GET /Items/{Id}/Similar` 私有播放列表泄露，以及 `streaming` 私有歌单封面跨用户读取；
  - 本地花絮递归继承父电影/剧集家长控制与分级并在 `/Items/{Id}/Ancestors` 过滤受限父条目；对齐虚拟库 `"collections"`/`"playlists"` 与 `Playlist` 容器策略；`loadRestrictedUserPolicy` 异常 fail-closed、`QueryItems` 空 `UserID` 用户态过滤返空集；
  - 修复 `ValidateTranscodingTempPath` `HasPrefix` 方向错误并在 `CleanTranscodeCache` 补齐系统目录前缀、`DataDir` 子目录与媒体库根目录防误删护栏；`imaging.Service` 补齐软链防越界校验与安全光栅图片格式校验。

### 流媒体、LiveTV、DVR 与后台同步修复 (Streaming, LiveTV & Admin Fixes)
- **消除转码全局锁车队冻结**：`transcode.Manager` 将 `lastAccess` 改为无锁 `atomic.Int64`，将 15s–45s 远程字幕烧录准备与 `StartLoopbackStreamProxy` 移出 `s.mu` 锁外执行，避免单会话阻塞拖慢全服播放与并发槽分配。
- **LiveTV、DLNA 与 DVR 加固**：
  - LiveTV 签名子目标绑定 `uid` 二次核验账号与策略状态并引入 45s 空闲租约计入 `SimultaneousStreamLimit`；录像列表与播放补齐目录与家长控制；
  - 修复取消频道手动映射未清旧 XMLTV 节目、删源残留孤立映射及 `RefreshAllGuides` TOCTOU；DVR 启动前占位防删除 TOCTOU、启动前异常回写 `Failed` 并透传调谐器 `UserAgent`；
  - DLNA 全量签发模式绑定令牌（关闭旧无模式兼容）并新增独立并发转码上限信号量（16）；DLNA 与音频直出按会话共享 `Range` 槽位。
- **内置插件配置同步、Offline Sync 与多语言任务**：
  - 修复 `TMDB` / `STRM` 内置插件在 `PluginsTab`、`SettingsTab` 与服务重启间的双向配置同步与元数据键透出问题；
  - Offline Sync 强制校验音视频转码权限、`ItemLimit`/空路径修复、SQL 前置权限过滤与 64 KiB 有界 FFmpeg 输出；补齐 `RefreshGuide`/`RefreshTunerHosts`/任务分类多语言本地化与 `TasksLogsTab` 语言切换刷新。

### Web 播放器内核、容器与 CI 修复 (Web Engines, Docker & CI)
- **`WasmRemuxer` / `StreamMkvRemuxer` / `BifParser`**：封堵 `//host` 协议相对路径与跨域重定向绕过 SHA-256、Worker 超时立即 `terminate()` 并限制 `finally` 2s 清理防 `remuxMutex` 死锁、避免 `AbortError` 污染本地核探针；修复 EBML 负帧长/Xiph 截断、`evictOldBuffers` 世代竞态、ISO 14496-1 四字节变长 `esds` 与 BIF 索引区/时间戳排序校验。
- **前端播放、Demo 与交付链路**：修复切集先 `video.load()` 归零覆盖续播进度、外挂音轨序号错位与服务端 HLS 路由、Watch Party/远控 `Playstate` 误拉起背景音乐、补全 `LIBRARY_CHANGED_KEYS` 与 Toast 超时限幅；对齐 Demo 模式权限与 `.zip` 备份契约；修复 `release.yml` 手动 `workflow_dispatch` 未检出目标 tag、`Dockerfile` 硬编码 `ENV` 覆盖 `ambra.json`、`docker/entrypoint.sh` 属主检查遗漏目录及 `Makefile` 前置构建前端。

## English

### Security & SSRF Hardening
- **Critical HLS / DASH Proxy Bypass Fix**:
  - Normalized `\r\n` and bare `\r` line endings before splitting in both `LoopbackStreamProxy` and LiveTV HLS rewriters, supported whitespace around `=` in `URI = "..."` attributes with fail-closed rejection of unrewritten tags, and rejected XML manifests (`<?xml`, `<MPD`, `<SmoothStreamingMedia`) with `502` to prevent FFmpeg DASH demuxer SSRF;
  - Enforced scheme matching in `isSameOriginHost`, bound post-redirect `effectiveURL` origin into `/sub`, and closed owned idle HTTP transports in `Close()`.
- **Notifications, Remote Access, Auth & Filesystem Guards**:
  - Restricted non-admin configured notification URLs to public hosts, stripped preserved masked secrets on origin changes, switched dispatch to a bounded 4-worker pool, and purged `compatext:state` notification services on user deletion;
  - Enforced global and per-user `EnableRemoteAccess` on unauthenticated WAN requests (avatars, `/Users/Public`, initial setup wizard) and disconnected active remote WebSocket clients when global remote access or LAN subnets are tightened at runtime;
  - Eliminated the disabled-account password oracle with constant-time dummy work, recorded login rate limits + throttled activity logs on `ErrUserDisabled`, added `ReadTimeout: 60s` (with overrides for WS/camera uploads), and returned `413` on oversized avatar/display-preference bodies;
  - Sealed private playlist leaks in `/Items/Latest`, `/Items/{Id}/Similar`, and cover artwork; propagated parent movie/series parental policies to local extras and `/Items/{Id}/Ancestors`; fixed `ValidateTranscodingTempPath` `HasPrefix` ordering and added system/`DataDir`/library-root guards to `CleanTranscodeCache`; added symlink and raster-format guards to `imaging.Service`.

### Streaming, LiveTV, DVR, Admin & Web Engine Fixes
- **Eliminated Global Transcode Lock Convoy**: Moved `lastAccess` to lock-free `atomic.Int64` and moved blocking subtitle burn-in staging + `StartLoopbackStreamProxy` outside `s.mu` in `transcode.Manager`.
- **LiveTV, DLNA, DVR & Sync**: Added `uid`-bound LiveTV signed sub-targets with revocation re-checks and 45s `SimultaneousStreamLimit` leases, fixed channel unmap EPG cleanup/orphaned mappings/`RefreshAllGuides` TOCTOU, enforced recordings RBAC, fixed DVR deletion TOCTOU/pre-start `Failed` status/`UserAgent` forwarding, switched DLNA to mode-scoped tokens with a 16-job transcode semaphore and shared `Range` slots (alongside Audio), fixed bidirectional `TMDB`/`STRM` plugin config sync, hardened Offline Sync transcode/limit/SQL-filtering/bounded-output paths, and localized `RefreshGuide`/`RefreshTunerHosts`/task categories.
- **Web Player Engines, Demo, Docker & CI**: Hardened `WasmRemuxer` (protocol-relative/redirect integrity checks, Worker timeout `terminate()`, `AbortError`-safe local probe), `StreamMkvRemuxer` (EBML/Xiph bounds, generation-scoped buffer eviction, 4-byte varint `esds`), `BifParser` (index bounds & timestamp sorting), `PlayerPage` (episode-switch resume preservation, external audio routing, `Playstate` isolation with `AudioPlayerContext`), `WebSocketContext`, `mockServer.ts`, `release.yml` (`workflow_dispatch` tag checkout `ref`), `Dockerfile`, `docker/entrypoint.sh`, and `Makefile`.
