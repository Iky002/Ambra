# Ambra v0.11.2 Release Notes / 版本发布说明

## 简体中文

### 安全、权限与隔离加固 (Security & Access Control)
- **物理删盘强警告与路径预览 (`DeleteInfo`)**：管理控制台「元数据管理」与前台「影片详情页」删除弹窗升级为高危物理删除红字警告，并实时拉取 `GET /emby/Items/{Id}/DeleteInfo` 展示即将从磁盘永久移除的媒体源文件、外挂字幕、NFO/海报及剧集全部分集路径清单。
- **同源 CORS / WebSocket 校验与动态热更新**：未配置 `AMBRA_ALLOWED_ORIGINS` 时默认严格限制同源请求并支持运行时动态热更新 `AllowedOrigins`；拦截跨站 `Origin` 对首次初始化接口（`/api/setup/*`、`/Startup/*`）的请求；移除 `WebSocket` 的 `InsecureSkipVerify` 并隔离 API Key 连接的用户隐私推送。
- **RBAC、水平越权与全链路家长控制闭环**：
  - 修复 `POST/DELETE /Sessions/{Id}/Users/{UserId}` 水平越权挂载；
  - 全链路强制执行用户策略 `EnableMediaPlayback`（禁播返回 `403`）；
  - DVR 录播库（`CollectionType: "livetv"`）全路径强制校验 `EnableLiveTvAccess`；
  - 将 `BlockUnratedItems` 与 `AllowedTags` 扩展家长控制策略完整下推至 SQL 查询、推荐、合集、花絮、Watch Party（`/Parties/*`）与离线同步等全部端点。
- **远端流与插件沙箱 SSRF 防护**：
  - `LoopbackStreamProxy` 新增 `.m3u8` HLS 清单安全重写代理模式，逐跳校验并本地签名重写子清单、`#EXT-X-KEY`、`#EXT-X-MAP` 及分片 URI，阻断清单内嵌内网/云元数据 SSRF 与二次 DNS Rebinding，同时保留同源 `.strm` 自定义请求头；
  - HDHomeRun 调谐器发现强制校验 `LineupURL` 同源与私网权限边界；
  - WASM 插件宿主 `ambra.http_request` 在每次 HTTP 重定向跳均复核 `AllowedHosts` 白名单；
  - DLNA `.strm` 流代理增加严格媒体 MIME 白名单与 `nosniff` + `Content-Security-Policy: sandbox`；
  - 媒体库与转码临时目录新增绝对路径、`EvalSymlinks`、系统敏感目录及 `DataDir` 重叠拦截；禁止通过 HTTP API 或备份恢复篡改宿主机 `FFmpegPath` / `FFprobePath`。
- **防爆破、防 OOM 与原子恢复**：
  - 未受信反代携带转发头时拒绝判定为局域网，回环地址改为独立高阈值限流桶，关闭远程访问时前置拒绝避免 Argon2id 算力消耗与口令预言机；
  - 私有播放列表可见性下推至 SQL 并引入 `json_each` 消除 `32766` 绑定变量上限与单用户歌单配额限制；`QueryItems` 下推 `IsHDR` / `VideoCodecs` / `IsLiked` 并增加安全分页上限；
  - `imaging` WebP 解码补齐 `VP8X` 帧尺寸扫描与 64 MiB 内存上限；
  - 备份恢复升级为配置、用户头像与 SQLite 数据库统一预检及失败原子回滚，修复热重启 `slog` 文件句柄重开问题。

### 播放、转码、直播与兼容能力增强 (Playback, Live TV & Compatibility)
- **Live TV HLS 滑动续签**：引入 HMAC 签名会话起始时间 `iat` 与滑动过期续签机制，彻底解决 HLS 直播观看满 10 分钟触发 `403` 断流的问题。
- **转码与并发流治理**：直连播放（`DirectPlay` / `DirectStream`）纳入 `SimultaneousStreamLimit` 并发槽位管控并修复 `TryAcquireStreamSlot` 并发竞态；补齐动态 HLS 码率上限钳制、`RemoteClientBitrateLimit` 与 `HEAD` 快速返回；修复管道转码写断开死锁漏槽；DVR 计划录制触发兜底时长正常收尾时正确标记 `StatusCompleted` 入库。
- **Emby 4.10.2.0 协议细节补齐**：支持音频 HLS 请求头 Token 注入与动态 `CODECS`、视频 HLS `StartTimeTicks` 与 `AddVttTimeMap`、内封字体提取透传 `.strm` 请求头、`POST /Library/Media/Updated` 按路径增量扫描、外部插件卸载同步清理磁盘目录、TMDB/TVDB `ImageProvider` 与 WASM `Notifier`、高级查询过滤/排序及 `?Sanitize=true` 日志脱敏导出。

### Web 影院、管理控制台与 10 国语言全量对齐 (Web UI, Admin & i18n)
- **播放器与前台体验**：修复初始定位前误报 `0` 抹除历史续播点、切集 `Stopped` 会话串号、`StreamMkvRemuxer` 片头 `QuotaExceededError` 前向缓冲驱逐、双流倍速重置、10-bit HEVC `hvcC` MIME、视频轨 Cues 过滤、`assRenderer` 并发序号守卫与 PGS 图形字幕按需懒解码；以 MIT 洁净室实现替换 `GPL-3.0` 的 `rvfc-polyfill`。
- **管理控制台补齐与防误触**：`PluginsTab` 与 `SettingsTab` 加载异常时显式报错并阻断保存，转码配置改为前后端增量合并；孤立项清理（含 NAS 挂载在线提醒）、删调谐器、移路径均增加二次确认弹窗；补齐用户策略开关（`IsHidden` 等）、单库刮削器启停与优先级排序、HDHomeRun 局域网扫描与频道 EPG 映射、离线同步任务队列监控及服务器重启/关机入口。
- **10 国语言 100% 覆盖**：完成全部 12 个公共组件/弹窗、7 个影院页面、API 错误提示及管理台新增功能的词条提取与翻译，10 国语言字典统一对齐至 **1,902 组词条**。

## English

### Security, RBAC & Isolation Hardening
- **Physical Disk Deletion Warnings & `DeleteInfo` Preview**: Updated deletion confirmation modals across Admin Metadata and Item Detail pages (and all 10 locales) with prominent irreversible disk-deletion warnings and live `GET /emby/Items/{Id}/DeleteInfo` file path previews.
- **Same-Origin CORS / WebSocket Enforcement & Dynamic Hot-Reload**: Enforced strict same-origin defaults when `AMBRA_ALLOWED_ORIGINS` is unset, wired live HTTP CORS hot-reload, blocked cross-origin browser requests to setup endpoints, and removed WebSocket `InsecureSkipVerify`.
- **RBAC, IDOR & End-to-End Parental Policy Enforcement**: Fixed cross-user IDOR on `/Sessions/{Id}/Users/{UserId}`, enforced `EnableMediaPlayback` across all playback/stream endpoints, gated `CollectionType: "livetv"` DVR libraries behind `EnableLiveTvAccess`, and pushed `BlockUnratedItems` and `AllowedTags` down across SQL queries, recommendations, extras, Watch Party (`/Parties/*`), and Sync endpoints.
- **SSRF, Sandbox & Path Protections**: Added HLS manifest URI verification and HMAC loopback rewriting to `LoopbackStreamProxy` (eliminating `#EXT-X-KEY` / segment SSRF and DNS rebinding while preserving same-origin `.strm` headers), enforced same-origin/LAN checks on HDHomeRun `LineupURL`, re-verified WASM `AllowedHosts` on every HTTP redirect hop, hardened DLNA `.strm` proxy MIME/CSP headers, validated library/transcode paths against system dirs and `DataDir`, and blocked overwriting host `FFmpegPath`/`FFprobePath` via API or backup archives.
- **DoS Mitigation & Atomic Restore**: Hardened untrusted-proxy LAN detection, loopback rate-limit buckets, and pre-Argon2id remote-access gates; pushed private playlist visibility and `IsHDR`/`VideoCodecs`/`IsLiked` into SQL with `json_each` variable chunking and safe pagination caps; bounded WebP `VP8X` frame dimensions and decode buffers; unified config/avatar/SQLite backup restore with atomic rollback.

### Playback, Live TV, Admin Console & 10-Locale Parity
- **Sliding Live TV HLS Tokens**: Added HMAC-signed session `iat` with sliding 10-minute expiration renewal so continuous Live TV HLS streams never drop with `403` at 10 minutes.
- **Streaming & Compatibility**: Enforced `SimultaneousStreamLimit` on direct streams with atomic slot reservation, clamped dynamic HLS bitrates, fixed pipe transcoding teardown leaks, preserved `.strm` headers on font extraction, implemented targeted `POST /Library/Media/Updated` path scans, disk cleanup on external plugin uninstall, TMDB/TVDB `ImageProvider`, WASM `Notifier`, and `?Sanitize=true` log redaction.
- **Web Player, Admin Console & 1,902-Key 10-Locale i18n**: Fixed pre-seek resume overwrite, episode-switch session snapshots, 4K MSE forward quota eviction, hybrid audio playback rate on seek, 10-bit HEVC `hvcC` MIME strings, lazy RLE PGS decoding, MIT `rvfcShim` replacement for `GPL-3.0` `rvfc-polyfill`, silent config-load data loss in Admin Settings/Plugins, confirmation modals for destructive actions, per-library scraper priority UI, HDHomeRun discovery & EPG mapping UI, Sync Jobs monitor, Server Restart/Shutdown controls, and full 10-locale UI localization (**1,902 keys × 10 languages**).
