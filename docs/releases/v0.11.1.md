# Ambra v0.11.1 Release Notes / 版本发布说明

## 简体中文

### 安全加固与管理能力 (Security & Administration)
- **登录页公开用户列表开关 (`EnableLoginUserList`，默认关闭)**：
  - 新增服务器配置项 `enable_login_user_list` / `EnableLoginUserList`（支持环境变量 `AMBRA_ENABLE_LOGIN_USER_LIST` 覆盖）与管理控制台「系统设置」可视化开关，同步覆盖全部 10 国界面语言。
  - 默认设为 `false`（隐藏），未认证请求访问 `/Users/Public` 与 `/emby/Users/Public` 默认返回空列表 `[]` 且附带 `Cache-Control: private, no-store`，防止未登录访客枚举服务器账号；管理员显式开启后恢复登录页快捷选号卡片展示。
  - 同步收紧未认证用户头像读取边界：当 `EnableLoginUserList` 关闭时，匿名访问 `/Users/{Id}/Images/Primary` 统一返回 `404`。

### 部署与在线体验修复 (Deployment & Demo Fixes)
- **修复 GitHub Pages 二级子路径静态资源 404 问题**：
  - 将 `web/vite.config.ts` 的 `base` 调整为读取 `VITE_BASE_PATH` 环境变量并默认回退 `./`，消除硬编码 `'/'` 导致的子目录挂载静态资源路径丢失。
  - 在 `.github/workflows/pages.yml` 中注入 `VITE_BASE_PATH: /${{ github.event.repository.name }}/`，自动兼容主仓库与 Fork 仓库的 GitHub Pages 子路径部署；同时在 `web/vercel.json` 中显式配置 `VITE_BASE_PATH=/ npm run build:demo` 兼顾根域名重写部署。

## English

### Security & Administration
- **Configurable Sign-In Public User List (`EnableLoginUserList`, Disabled by Default)**:
  - Added `enable_login_user_list` / `EnableLoginUserList` server configuration (with `AMBRA_ENABLE_LOGIN_USER_LIST` environment override) and an admin toggle in **Admin Console → Settings** across all 10 locales.
  - Disabled (`false`) by default so unauthenticated `GET /Users/Public` and `GET /emby/Users/Public` return `[]` with `Cache-Control: private, no-store`, preventing anonymous account enumeration. Administrators can opt in to restore the quick-select user strip on the sign-in screen.
  - Hardened unauthenticated `GET/HEAD /Users/{Id}/Images/Primary` to return `404` whenever `EnableLoginUserList` is disabled.

### Deployment & Demo Fixes
- **Fixed GitHub Pages Subpath Static Asset 404s**:
  - Updated `web/vite.config.ts` to resolve `base` from `VITE_BASE_PATH` with a `'./'` default instead of forcing `'/'` on demo builds.
  - Configured `.github/workflows/pages.yml` with `VITE_BASE_PATH: /${{ github.event.repository.name }}/` for subpath deployments and `web/vercel.json` with `VITE_BASE_PATH=/ npm run build:demo` for root-level SPA rewrites.
