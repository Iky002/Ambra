## v0.10.9 全量安全加固、并发稳定与播放体验修复

本版本基于对 `v0.10.8` 全仓库 **224 / 224** 个非测试文件的全量深度审计，一次性修复全部 **21 项 High、52 项 Medium 与 36 项高价值 Low** 问题，全面加固凭据安全、SSRF 防线、并发竞态与优雅停机收敛，并提升播放器与管理后台交互体验。

### 安全加固
- **插件换 Host 凭证保护端到端闭环**：修复 `pluginadmin` 合并旧明文密钥绕过 Host 变更清空凭证的问题；TMDB 仅在官方默认 Host 时允许回退内置默认 API Key；屏蔽 TVDB `pin`、`credential`/`authorization`/`cookie` 明文泄露；移除 Trakt 运行时 `base_url` 覆盖能力；插件 `Configure()` 改为先全量校验再提交，失败时自动回滚内存状态。
- **SSRF 与播放/流媒防线**：Live TV DVR 调度与录制器严格继承 `TunerHost.AllowPrivateNetwork` 策略；Live TV HLS 签名子播放列表禁止链式无限续期并缩短单次签名 TTL；音频 STRM FFmpeg 补齐 `-follow_redirects 0` 与 `-rw_timeout`；视频远程文本字幕硬烧录禁止直传 HTTP URL 至 `subtitles=` 滤镜（改为安全限额下载/提取本地暂存）。
- **认证、会话与访问控制**：Token/API Key/设备吊销改为先删 SQLite 再清缓存并引入单调 `revokeEpoch` 防并发复活；`ReportPlaybackStart` 禁止空 `ItemId` 伪造 `NowPlayingItem`；登录与 QuickConnect 统一校验 `Policy.EnableRemoteAccess`；补齐 6 个附属媒体接口及媒体库封面回退的家长控制过滤；收敛私密播放列表在 `LiveStreams/Open` 与合集接口中的隔离边界；敏感凭证响应统一添加 `Cache-Control: private, no-store`；`POST /Notifications/Admin` 未指定目标 `UserId` 时默认 `AdminOnly: true` 并忽略空 `UserId` 事件防误广播；收紧 Sync/DLNA 符号链接边界与 GENA/SOAP 限流及 `TypedSettings`/KV 大小限制。

### 稳定性、并发与停机收敛
- **DVR 与优雅停机**：修复 `dvr.Recorder` 的 `entry.stdin` 并发竞态与 `defer` LIFO 逆序误触发 `gracefulStop`；Webhook Worker 改用可取消 Context 消除停机最长 10 分钟阻塞；`Server.Close()` 补齐 Trakt 8-worker 退出、`Scheduler.Shutdown` 等待与 `Migrator.Wait` 收敛，并支持取消后台 BIF 生成任务。
- **转码、扫描与存储**：修复并发 Seek 后旧分片请求死等并 `touch()` 阻止会话回收；修复文本字幕烧录 Seek（`-copyts`）下的关键帧风暴；修复 `ExtractFonts` 失败写入 `.extracted` 永久负缓存并增加附件数量/体积上限与流式输出；修复 SQLite v5 用户名去重碰撞、Migration v6 重复开写事务、v0.10.8 `trakt_repo` 缺 `guid.Normalize`、`usertrakt` 全局锁内网络 I/O、`LibraryRepo` 计数缓存并发竞态及多版本合并并发写孤儿记录；增量目录删除支持按路径前缀清理子项。
- **CI / 发布流水线**：预发布 Tag（如 `-rc.1`）自动标记 `prerelease: true` 且不再覆盖 `:latest`/`:full`/`:lite` 镜像；移除 BtbN FFmpeg 跨分支静默回退。

### Web 播放器与管理后台
- 修复 `AuthContext.refreshUser()` 切号异步竞态导致跨账号身份/Token 污染。
- 修复 Demo 部署 CSP `media-src` 缺失 `data:` 阻断演示音视频与字幕播放；Demo 构建改用 `base: '/'` 避免二级路径白屏；Vite 开发代理补齐 `/api`。
- 修复首播音轨偏好触发二次建流与切音轨销毁重下 BIF；修复 `StreamMkvRemuxer` 与 `PgsCanvasRenderer` 切换/Seek 竞态及 `seekBy` 在异常时长下归零。
- 修复 `PluginsTab` 异步串写竞态与误删第三方插件字段、弹窗内独立错误提示、`MetadataEditorModal` 保存锁定时清空未保存编辑、`ItemDetailPage` 删除剧集/单曲路由、`LibraryPage` 制片厂服务端分页筛选及触控屏交互可达性。

### English

Comprehensive security hardening, concurrency stability, and web player fixes covering all 21 High, 52 Medium, and 36 high-value Low findings from the full `v0.10.8` audit (224/224 source files):
- **Security**: End-to-end plugin host-change credential clearing (including TMDB built-in fallback key isolation and TVDB `pin` masking), Live TV DVR `AllowPrivateNetwork` enforcement and non-renewable HLS proxy signatures, FFmpeg redirect SSRF hardening for audio STRM and remote subtitle burn-in, race-free token revocation epochs, parental control enforcement across extras/library covers, `EnableRemoteAccess` checks on login, and `Cache-Control: private, no-store` on credential responses.
- **Reliability**: Fixed DVR `stdin` data race and LIFO `defer` shutdown bug, cancellable Webhook/Trakt/Scheduler/Migrator/BIF graceful shutdown, transcode concurrent-seek stall and `-copyts` keyframe storm, `ExtractFonts` negative-cache and size limits, SQLite v5 username dedup collision, `trakt_repo` GUID normalization, and prerelease Docker tag safety.
- **Web UI**: Fixed `AuthContext` account-switch race, Demo CSP `data:` media support and Vite `/api` proxy, PlayerPage double-mount and BIF cache preservation on audio switch, PluginsTab modal race and third-party field preservation, and backend studio pagination.
