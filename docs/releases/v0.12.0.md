# Ambra v0.12.0 Release Notes / 版本发布说明

## 简体中文

### 直播电视播放稳定性加固 (LiveTV Playback Hardening)
- **HLS 直播播放器全面调优 (`LiveTvPage.tsx`)**：
  - 关闭不适用于普通 IPTV M3U8 的激进低延迟模式（`lowLatencyMode: false`），放宽直播同步与缓冲/重试参数（`liveSyncDurationCount: 3`、`liveMaxLatencyDurationCount: 10`、`maxBufferLength: 30`、`backBufferLength: 30`、`manifestLoadingMaxRetry: 4`、`levelLoadingMaxRetry: 4`、`fragLoadingMaxRetry: 6`），大幅降低 live-edge 追帧导致的缓冲断层与解码报错；
  - 将致命 `MEDIA_ERROR` 与 `NETWORK_ERROR` 恢复上限提升至 **10 次**，引入递增冷却延迟（`500ms → 3000ms`），偶数次媒体恢复自动调用 `swapAudioCodec()`，网络错误通过 `startLoad()` 续连；连续稳定播放 **15 秒** 后自动清零恢复计数；
  - 对 `bufferAddCodecError` / `manifestIncompatibleCodecsError` 编码不兼容错误快速失败并提示明确原因；所有 HLS 错误文案均透出底层技术明细 `(${details})` 便于排查；
  - 为直播 `<video>` 增加 `key` 彻底隔离跨频道 MSE 管线，保留并还原音量/静音偏好，收敛 `useEffect` 依赖避免频道列表刷新触发误重建，补齐 `cancelled` 守卫、`video.load()` 清理与 HLS 托管模式下的 `<video onError>` 防误报。
- **非 HLS 连续流 TS 包边界对齐 (`stream_hub.go`)**：
  - 在 `LiveStreamHub` 重放环形缓冲给新订阅者时，自动扫描并截断至首个有效 MPEG-TS `0x47` 同步包边界（优先校验连续 3 包 `0x47`），避免切台或复用流时向解码器注入半截 TS 包导致首包解析失败。

### M3U / HDHomeRun 频道源自动与手动刷新 (Tuner Host Refresh)
- **后端刷新引擎与接口 (`handler.go`)**：
  - 新增 `RefreshTunerHost(ctx, id)` 与 `RefreshAllTunerHosts(ctx)`：自动跳过纯手工粘贴的离线 M3U 源，仅刷新配置了 `Url` 的远程 M3U / 本地 M3U 文件 / HDHomeRun 调谐器；
  - 无锁执行上游拉取并在写回前二次校验调谐器存在性；内置空列表与上游异常保护，失败或返回 0 频道时保留现有频道列表不清空；
  - 复用 `deterministicChannelID` 实现无损更新（保留频道排序、禁用状态、EPG 映射与录制计划），并为无 `tvg-id` 且名称唯一的旧频道在换流地址时回退继承 `Disabled` 与 `SortIndex`；
  - 新增管理员接口 `POST /LiveTv/TunerHosts/{Id}/Refresh`（同时支持 `/emby/LiveTv/TunerHosts/{Id}/Refresh`）。
- **后台定时刷新任务 (`server.go`)**：
  - 注册独立后台计划任务 **「刷新直播电视频道源 (M3U / HDHomeRun)」**（`refresh-livetv-tuners`，`Category: "LiveTV"`），默认每 **6 小时** 自动同步一次，可在管理后台「计划任务与日志」自由调整触发器。
- **管理后台 UI、Demo 与 10 国语言**：
  - 在 `LiveTvTab` 为每个配置了 URL 的 M3U / HDHomeRun 调谐器卡片新增「刷新」按钮（含加载动画、最新导入频道数提示及频道列表自动刷新）；
  - 同步补齐在线 Demo `POST /emby/LiveTv/TunerHosts/{Id}/Refresh` 路由与全部 **10 国语言包**（**2,045 组词条 × 10 语种**）。

## English

### LiveTV Playback Hardening
- **Frontend HLS Live Player Resilience (`LiveTvPage.tsx`)**:
  - Disabled aggressive LL-HLS chasing (`lowLatencyMode: false`) for standard IPTV M3U8 streams and tuned live sync, buffer, and loader retry thresholds (`liveSyncDurationCount: 3`, `liveMaxLatencyDurationCount: 10`, `maxBufferLength: 30`, `backBufferLength: 30`, `manifestLoadingMaxRetry: 4`, `levelLoadingMaxRetry: 4`, `fragLoadingMaxRetry: 6`).
  - Raised fatal `MEDIA_ERROR` and `NETWORK_ERROR` recovery budgets to **10 attempts** with linear backoff (`500ms → 3000ms`), `swapAudioCodec()` on even media recovery attempts, `startLoad()` for network recovery, and automatic counter reset after **15 seconds** of stable playback (`FRAG_BUFFERED` / `playing`).
  - Added immediate fast-fail for unsupported codecs (`bufferAddCodecError` / `manifestIncompatibleCodecsError`), appended technical `(${details})` context to HLS error messages, isolated `<video>` MSE pipelines per channel/mode/retry via React `key` (while preserving `volume`/`muted`), stabilized `useEffect` dependencies against channel-list refetches, and guarded against stale callbacks and native `<video onError>` noise while `hls.js` is active.
- **MPEG-TS `0x47` Sync Alignment (`stream_hub.go`)**:
  - Aligned initial `LiveStreamHub` ring buffer replays to the first verified 188-byte MPEG-TS `0x47` sync packet boundary (checking 3 consecutive sync bytes with 2-byte fallback for short buffers) so new/reconnecting viewers never receive leading partial TS packets.

### M3U / HDHomeRun Tuner Host Refresh
- **Backend Refresh Engine & API (`handler.go`)**:
  - Added `RefreshTunerHost(ctx, id)` and `RefreshAllTunerHosts(ctx)` to refresh URL-backed M3U (remote/local file) and HDHomeRun tuner hosts while skipping inline pasted M3U sources.
  - Performs upstream fetches lock-free with empty-response and upstream-error protection (never wiping existing channels on failure or empty payload), preserves `Disabled`, `SortIndex`, EPG mappings, and DVR timers via `deterministicChannelID` (plus unique-name fallback for channels without `tvg-id`), and exposes `POST /LiveTv/TunerHosts/{Id}/Refresh` (admin-only).
- **Scheduled Task, Admin UI, Demo & 10-Locale i18n**:
  - Registered the `refresh-livetv-tuners` (`Key: "RefreshTunerHosts"`, `Category: "LiveTV"`) scheduled task running every **6 hours** by default.
  - Added a per-tuner Refresh button with loading spinner and channel-count feedback in `LiveTvTab`, added Demo `mockServer` parity, and synchronized all **10 locales** (**2,045 keys × 10 languages**).
