## v0.11.0 全量深度安全加固、Emby 兼容桩真实化与 10 语种管理后台补齐

本版本基于对全仓库 **100% 源文件**的深度安全与能力审计，一次性完成 **48 项安全与稳定性问题修复**，并将 **22 项未完成兼容桩全部升级为真实可用实现**，同时补齐 14 个管理后台模块的 **10 语种（987 键）国际化**与 WebP / 内嵌歌词 / 共享直播流等核心能力。

### 升级与行为变更注意
- **DLNA 默认关闭**：新安装或未显式开启时 `EnableDLNA` 默认为 `false`；如需使用电视局域网发现与投屏，请在「管理控制台 → 服务器设置」开启并按需绑定默认受限用户（`DLNADefaultUserID`）。
- **删除媒体同步移除物理文件**：具备管理员或 `EnableContentDeletion` 权限的用户执行删除媒体操作时，在校验物理路径严格位于所属媒体库根目录内（`EvalSymlinks` 防越界）后，将同步清理磁盘媒体文件与受控伴生文件（字幕、`.nfo`、海报）；虚拟容器（`BoxSet` / `Playlist`）仅删除关联记录。

### 安全与权限加固
- **跨源重定向防 Token 泄露与双通道鉴权**：Web 端与 HLS 请求统一改用标准 `Authorization: MediaBrowser ..., Token="..."` 请求头（跨源 302 跳转自动剥离），后端兼容标准头与传统客户端头，并将 URL `api_key` 限定于媒体流/图片/字幕/WebSocket 路径。
- **FFmpeg 与网络边界 SSRF 防护**：远端媒体转码引入受控本地回环代理并强制 `-max_redirects 0`；收紧 `TrustedProxies`、远程访问白名单、Webhook 安全投递与 DLNA GENA 回调防回环校验；找回密码 PIN 文件权限收紧至 `0600` 且不再回显物理路径。
- **家长控制 Fail-Closed 与 RBAC 全路由基线**：未知分级标签默认按高风险拦截，杜绝合集/剧集空壳或元数据侧漏；补齐 `/web/ConfigurationPages`、Watch Party 等接口鉴权与全量 RBAC 自动化基线审计。

### Emby 4.10.2.0 真实能力补齐
- **系统与协同**：`/System/Restart` 进程内热重载与 `/System/Shutdown` 优雅停机；`/Devices/CameraUploads` 二进制流式原子落盘与 SHA-256 去重；Watch Party `/Parties/*` WebSocket 实时播放进度同步；数据库恢复前自动创建回滚快照并执行 `PRAGMA integrity_check`。
- **转码、离线同步与图像**：`/Encoding/*` 动态转码与硬件加速配置持久化及 `EnableThrottling` 节流；后台 `Sync` FFmpeg 离线转码队列与产物分发；新增纯 Go WebP 图像解码与动态输出支持。
- **音频、字幕、LiveTV 与插件宿主**：解析 MP3 (`USLT`/`SYLT`)、FLAC (`LYRICS`)、M4A (`©lyr`) 内嵌歌词并支持 `/Audio/{Id}/hls1/...` 自适应流；对接插件源实现远程字幕搜索与下载；新增 `LiveStreamHub` 共享环形缓冲、HDHomeRun 自动发现、EPG 频道映射、系列追录与 DVR 录像 HLS 回放；WASM 插件宿主注入受 SSRF 与域名白名单约束的 `ambra` HTTP/日志能力；支持每媒体库独立刮削选项与本地伴生资产发现。

### Web 播放器、管理后台与 10 语种国际化
- **播放器稳定性**：`StreamMkvRemuxer` 扩容 >4MB 4K 关键帧缓冲、补齐 5.1/7.1 多声道 Opus `dOps` 沟道映射表并自动驱逐 MSE `QuotaExceededError` 旧缓冲；`wasmRemuxer` 修复无原生杜比/DTS 解码时误走 `videoOnly` 静音问题；支持片头跳过与在线搜挂字幕。
- **管理后台与 Demo**：`zh-CN`、`zh-TW`、`en-US`、`ja-JP`、`ko-KR`、`fr-FR`、`de-DE`、`es-ES`、`pt-BR`、`th-TH` 全部对齐 **987 个词条键**；Demo 模式实现多账号按 Token 严格 RBAC 隔离，并在正式生产构建中编译期静态剥离 Demo 模块。
