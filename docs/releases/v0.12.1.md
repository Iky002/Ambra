# Ambra v0.12.1 Release Notes / 版本发布说明

## 简体中文

### 安全加固与网络边界 (Security & SSRF Hardening)
- **`.strm` 代理、HLS 子资源与远程探测全面防 SSRF**：
  - `netutil.NewSafeHTTPClient` 跨主机名重定向（Cross-Host Redirect）在 `CheckRedirect` 与 `DialContext` 双重强制切换为纯公网地址校验（阻断 30x 跳转至回环、RFC1918/ULA 内网、CGNAT 及跨跳转 DNS Rebinding）；
  - `LoopbackStreamProxy` `/sub` 跨源子资源请求强制禁止访问私网地址（`allowSubPrivateLAN = opts.AllowPrivateLAN && sameHost`），并在重定向拦截前提前剥离跨站敏感头；
  - `Scanner` 远程 `ffprobe` 探测统一接入 `LoopbackStreamProxy` 并附带 `-rw_timeout 15000000`，消除 FFmpeg `< 8.1` 剥离 `-follow_redirects 0` 后的重定向与 DNS Rebinding 风险；
  - LiveTV 的 M3U 与 XMLTV 抓取严格执行 `AllowPrivateNetwork` 策略，防止公网播放列表/节目单源探测内网。
- **密码重置 PIN、登录限流与权限边界加固**：
  - 忘记密码 PIN 新增单 PIN 错误次数硬上限（累计 5 次错误自动销毁 PIN 与 `passwordreset-*.txt` 文件），并对 `forgotClientIP` 补齐 IPv6 `/64` 聚合；
  - 重构登录复合限流桶淘汰与单 IP 子桶上限（`maxSubBucketsPerIP = 8`），消除填满 4,096 复合桶导致的无关正常用户全局 `429` 拒绝服务；
  - 修复 `loadRestrictedUserPolicy` / `IsItemBlockedByPolicy` 在 `EnableAllFolders: false` 且 `EnabledFolders == nil` 时的放行缺口，`GetItemByID` 子项统计严格套用 `allowedLibs`，`isChildVisibleToUser` 透传真实用户 `EnableLiveTvAccess` 策略；
  - 用户头像接口补齐 `EnableRemoteAccess` 校验与非管理员对隐藏/禁用账号的隔离；Watch Party 加入房间二次校验 `ItemId` 竞态并按成员权限脱敏 `Playstate` WS 广播。
- **CI 供应链安全加固**：
  - `release.yml` 默认锁定 BtbN 永久月末版本 `autobuild-2026-10-31-12-59` 及对应 Linux/Windows 静态包 SHA-256 摘要；
  - 全量锁定 `.github/workflows/{ci,pages,release}.yml` 中所有 GitHub Actions 至精确 40 位 commit SHA，并收紧 `pages.yml` 各阶段最小权限。

### 流媒体、存储、调度器与 Web 稳定性修复 (Stability & Playback Fixes)
- **LiveTV、DLNA 与流并发管控**：
  - 无 `tvg-id` 频道在刷新换流地址且名称唯一时直接复用原 `Channel.Id`，完整保留 EPG 节目单、频道映射与 DVR 预约/追录计划；`RefreshTunerHost` 补齐写回前并发修改 TOCTOU 冲突保护（`409 Conflict`）；LiveTV HLS 标签重写兼容大小写与无引号 `URI=`；
  - DLNA 流补齐音视频转码策略校验、模式绑定签名与直出/`.strm` 代理并发流槽位管控；LiveTV 初始播放接入并发流上限，Audio HLS `HEAD` 探测不再占用流槽位；所有临时回退 `http.Client` 自动回收空闲连接。
- **SQLite、离线同步、备份与缓存清理**：
  - `SearchHints`、`GetQueryFilters`、`ListFilterValuesWithUserPolicy` 的 `IncludeItemTypes` 全面接入 `json_each` 安全集合分流；
  - `POST /Sync/JobItems/{Id}/Enable` 补齐下载权限与媒体 ACL 校验及安全状态机流转，`OnLibraryItemAdded` 纳入单用户与全局配额限制；
  - 备份恢复前自动清理上一次残留的 `.restore` 暂存配置与元数据；`CleanTranscodeCache` 对顶层文件同样执行 2 小时最小存活保护并新增系统目录安全护栏；补齐 `library/Media/Updated` 与 `.strm` 符号链接越界校验。
- **Web 播放器、LiveTV 与管理台修复**：
  - `PlayerPage` 补齐 HLS 托管模式 `<video onError>` 守卫、致命错误耗尽后 `hls.destroy()` 释放、初始续播进度防覆写清零、OSD 面板打开时防误隐藏及 PGS 字幕异步取消清理；
  - `LiveTvPage` 拆分独立的媒体/网络恢复定时器，卡顿/暂停时自动重置稳定播放计时器，修复 DVR 录像 HLS 降级直出错误条残留、EPG 查询缓存键与切台双初始化问题；
  - `client.ts` 拦截旧会话在途请求返回 `401` 误踢新登录会话；修复 `LiveTvTab` 多调谐器并发刷新状态互清、`HealthAndAuditTab` 孤儿清理后刷新容错与 `SettingsTab` 数字输入清空问题。

## English

### Security, SSRF & Supply-Chain Hardening
- **SSRF Protection Across `.strm` Proxies, HLS `/sub`, Remote `ffprobe`, and LiveTV Metadata**:
  - Enforced public-only validation in both `CheckRedirect` and `DialContext` on cross-hostname redirects in `netutil.NewSafeHTTPClient` (blocking loopback, RFC1918/ULA LAN, CGNAT, and DNS rebinding);
  - Restricted `LoopbackStreamProxy` cross-origin `/sub` sub-resources to public IPs (`allowSubPrivateLAN = opts.AllowPrivateLAN && sameHost`), routed remote `ffprobe` probing through `LoopbackStreamProxy` with `-rw_timeout 15000000`, and enforced `AllowPrivateNetwork` on M3U and XMLTV fetches.
- **Auth, RBAC & CI Supply-Chain Hardening**:
  - Added IPv6 `/64` normalization to `forgotClientIP` and a 5-attempt failure cap per password-reset PIN; eliminated global `429` login DoS on composite rate-bucket saturation via per-IP sub-bucket caps (`maxSubBucketsPerIP = 8`) and oldest non-locked eviction;
  - Closed library RBAC fail-open when `EnableAllFolders: false` with `EnabledFolders == nil`, scoped `GetItemByID` child counts by `allowedLibs`, propagated real `EnableLiveTvAccess` in `isChildVisibleToUser`, enforced `EnableRemoteAccess` & hidden/disabled checks on user avatars, and closed Watch Party `ItemId` join TOCTOU & WS broadcast leaks;
  - Pinned default BtbN FFmpeg release (`autobuild-2026-10-31-12-59`) with hardcoded SHA-256 digests, pinned all GitHub Actions across `ci.yml`, `pages.yml`, and `release.yml` to immutable 40-char commit SHAs, and scoped `pages.yml` job permissions.

### Streaming, Storage, Scheduler & Web UI Fixes
- **Backend Streaming & Maintenance**: Preserved `Channel.Id` (and EPG/DVR links) on URL rotation for uniquely named non-`tvg-id` channels, added TOCTOU protection (`409`) to `RefreshTunerHost`, handled case-insensitive/unquoted HLS `URI=` attributes, enforced DLNA transcode policies/mode tokens/`SimultaneousStreamLimit` (plus LiveTV stream slots and Audio HLS `HEAD` exemption), applied `json_each` to `IncludeItemTypes`, hardened Sync `Enable` RBAC/state transitions & `SyncNewContent` quotas, cleaned stale `.restore` files on backup staging, enforced 2h age & directory guards in `CleanTranscodeCache`, and added symlink containment checks to `Media/Updated` and `.strm` resolution.
- **Web Player, LiveTV & Admin**: Guarded `PlayerPage` `<video onError>` during active `hls.js` playback, destroyed `Hls` workers on fatal exhaustion, protected resume ticks before initial seek, fixed `pokeOsd` stale panel closure & PGS post-await cleanup; isolated `LiveTvPage` media vs network recovery timers with stall-aware reset, fixed DVR fallback banner & EPG query keys; ignored stale-token `401` responses in `client.ts`; and fixed concurrent tuner refresh state in `LiveTvTab`, post-cleanup audit refresh handling in `HealthAndAuditTab`, and empty numeric input handling in `SettingsTab`.
