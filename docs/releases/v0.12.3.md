# Ambra v0.12.3 Release Notes / 版本发布说明

## 简体中文

### 安全加固与网络边界 (Security & SSRF Hardening)
- **LiveTV 签名身份防伪造与租约隔离**：`ProxyChannelStream` / `proxyChannelStreamWithSession` 不再信任未签名查询参数 `?uid=`，未签名入口严格绑定当前认证用户，仅 `handleStreamChannel` 在通过 HMAC 验签后传递已验签 `uid`，封堵绕过 24 小时吊销校验与碰撞复用他人直播租约的风险。
- **`LoopbackStreamProxy` XML/DASH 嗅探全量加固**：按 `Content-Type` 直接拒绝 `application/dash+xml`、`application/vnd.ms-sstr+xml`、`application/xml`、`text/xml` 及 `*+xml` 响应；`isXMLManifestPayload` 扫描完整归一化嗅探缓冲，全面拦截带前导 XML 注释（`<!-- ... --><MPD`）、`<!DOCTYPE>` 或超长前导空白的 DASH/ISM 清单。
- **远程探测与通知测试权限收紧**：
  - `Prober.Probe` 生产路径移除直接回环放行（恒定 `DisallowLoopback: true`，仅保留非导出测试开关）；
  - 非管理员调用 `POST /Notifications/Services/Test` 传空 `{}` 返回 `403`，且不再触发全服管理员通知插件（`registry.Notifiers()`）；
  - `ws.Hub.DisconnectRemoteClients` 记录握手原始 peer IP 与代理头标记，收紧 `TrustedProxies` 时立即断开不再受信任代理接入的存量 WebSocket；
  - `UpdateNamedConfiguration` 接入 `LimitReader(1 MiB + 1)` 超限返回 `413`；`fetchRemoteImage` 落盘前执行光栅图片魔数校验（JPEG/PNG/WebP/GIF/BMP/AVIF）。

### 后端存储、LiveTV、转码与配置修复 (Backend Stability Fixes)
- **LiveTV 频道映射与 EPG 并发一致性**：`RefreshAllGuides` 在并发新增/修改 XMLTV 源时自动跳过全局清扫避免误删刚导入节目；新增同步方法 `compatext.Handler.PruneOrphanedChannelMappings` 并接入 `livetv` 回调，消除删源后内存态与 SQLite 失步复活旧映射的问题。
- **环境变量优先级、计数过滤与清理修复**：
  - `AMBRA_TMDB_API_KEY` 处于环境变量覆盖时，`syncTMDBPlugin` 不再将其烘焙写入 SQLite，且启动加载 `ApplySavedConfigs` 后自动保持环境变量最高优先级；
  - `GetItemCountsForUser` 统计本地预告片关联父电影家长控制策略（同时兼容库顶层预告片），并对空 `userID` 非管理员在 `GetItemCountsForUser` 与 `GetContainerItemsWithUserPolicy` 统一执行私有歌单隔离；
  - 修复 `ScanPath` 在合法软链子目录内删除文件时对已不存在目标调用 `EvalSymlinks` 失败的问题；`transcodeSession.startProcessUnlockRelock` 并发销毁时自动清理残留 `workDir`。

### Web 播放器内核、管理台与 CI 修复 (Web Engines, Admin UI & CI)
- **前端播放与重封装引擎**：
  - 修复 `AudioPlayerContext` 在 `<HashRouter>` 下仅检查 `window.location.pathname` 导致观影/背景音乐 `Playstate` 隔离失效的问题（同时识别 `window.location.hash` `#/play/...`）；
  - 修复 `StreamMkvRemuxer` 跳过超大非媒体 EBML 元素时双重累加 `parsed.consumedBytes` 导致的偏移错位，并为 `appendToBuffer`/`appendBufferOnce`/`evictForQuotaRecovery` 补齐 `generation` 世代竞态保护；
  - 修复 `WasmRemuxer.ensureLoaded` 在回退下一 CDN 时复用脏实例与泄漏超时 Worker；`PlayerPage` 切集 `playbackInfo` 查询门控 `episodeIdSynced === id`，消除切集首帧错配请求。
- **管理台弹窗、Demo 契约与发布流水线**：
  - `AdminModal` 引入全局弹窗栈（仅栈顶弹窗响应 `Escape`），修复嵌套弹窗按 `Escape` 误关底层“编辑媒体库”弹窗的问题；为备份恢复、踢出设备、吊销 API Key、删除调谐器、保存任务触发器与取消同步任务等确认弹窗补齐弹窗内错误提示；
  - Demo 模式 `/emby/Playlists/{id}` 严格校验 `container.Type` 与创建者/管理员权限；`release.yml` 为 `docker/metadata-action` 补充 `context: git`，确保手动 `workflow_dispatch` 按目标 tag commit 正确生成 `sha-*` 标签与 OCI revision。

## English

### Security & Network Hardening
- **LiveTV Unsigned `uid` Fix & XML/DASH Sniffing Hardening**: Removed unsigned `?uid=` trust from `ProxyChannelStream`/`proxyChannelStreamWithSession` so only HMAC-verified `handleStreamChannel` sub-targets carry a verified `uid`; hardened `LoopbackStreamProxy` to reject XML/DASH/ISM `Content-Type`s and scan the full normalized sniff buffer for comments, `<!DOCTYPE>`, `<MPD`, `<SmoothStreamingMedia`, and whitespace-only preambles.
- **Probe, Notifications, WebSocket & Image Hardening**: Enforced `DisallowLoopback: true` in production `Prober.Probe`; blocked non-admins from triggering global `registry.Notifiers()` via `POST /Notifications/Services/Test`; enhanced `ws.Hub.DisconnectRemoteClients` to re-evaluate `TrustedProxies` tightening using recorded peer IPs and proxy-header flags; added `LimitReader+1` (`413`) to `UpdateNamedConfiguration`; added raster magic-byte verification (JPEG/PNG/WebP/GIF/BMP/AVIF) to `fetchRemoteImage`.

### Backend Stability, Web Player Engines, Admin UI & CI
- **LiveTV, SQLite, Scanner & Config**: Fixed `RefreshAllGuides` stale-program sweep racing with concurrent provider additions, synchronized `PruneOrphanedChannelMappings` between `livetv` and `compatext` memory/SQLite state, preserved `AMBRA_TMDB_API_KEY` env-var precedence over SQLite plugin sync, joined parent movie parental policies in `GetItemCountsForUser` `TrailerCount` and enforced `publicOnly` playlist visibility for empty-`userID` non-admin queries, fixed `ScanPath` incremental deletion inside valid symlinked subdirectories, and cleaned up orphaned `workDir` on concurrent `transcodeSession` destruction.
- **Web Player, Admin & CI**: Fixed `AudioPlayerContext` `<HashRouter>` `#/play/` detection, fixed `StreamMkvRemuxer` oversized EBML skip double-counting and generation-scoped `appendToBuffer`/`appendBufferOnce`, prevented `WasmRemuxer` worker leaks across fallback bases, gated `PlayerPage` `playbackInfo` on `episodeIdSynced === id`, added stacked `AdminModal` `Escape` isolation and in-modal error banners across 4 admin tabs, enforced Demo playlist type/ownership checks, and added `context: git` to `docker/metadata-action` in `release.yml`.
